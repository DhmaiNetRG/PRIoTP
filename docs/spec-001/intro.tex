\chapter{Introduction}
This specification describes a publish-subscribe protocol for Internet-of-Things
(IoT)
client-server exchange. In the typical scenario there is a set of sensors that
send periodical updates to a server. The server should collect sensor data while
accepting subscriptions from clients that are interested in particular subset of
sensor updates. Once a client is subscribed to some sensors it should receive updates
the same way as the server receives them from the sensors. When the client is no
longer willing to receive updates from the server it should unsubscribe from the
updates.

The protocol specification described in this document has a few design goals
which one should be familiar of to understand the design choices made. First of
all to our understanding the IoT style communication is going to be used with
multiple sensors and multiple clients. The sensors have different
characteristics; they send updates at different rates, the size of the updates
vary as does their content types. We are not to limit what kind of data the
sensors can produce. Another key design choice made is not to provide fully
reliable transmission. IoT communication patterns are usually making of use the
most recent data and offering full reliability service is out of the scope of
this specification.
